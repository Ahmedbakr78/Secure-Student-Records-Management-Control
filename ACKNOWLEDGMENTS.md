# Acknowledgments

SRMS exists because database security is best learned by building the controls, breaking them, and documenting the evidence.

## Academic context

- The project was developed as a **Database Security term project** in two phases.
- The security model sequence follows the course material on access control, inference control, flow control, multilevel security, and encryption.
- The role-request workflow was completed as **Part B** of the course project.

## Security foundations

| Concept | Source |
| :-- | :-- |
| Role-Based Access Control | NIST RBAC model (Sandhu et al.) |
| Bell–LaPadula | *Secure Computer Systems: Mathematical Foundations and Model* (1973) |
| Inference control | Statistical database security and query-set-size control literature |
| Salted password hashing | OWASP Password Storage Cheat Sheet |
| Authenticated encryption | `cryptography` Fernet specification |
| SQL Server encryption | Microsoft SQL Server encryption hierarchy documentation |

Static validation

Checks that need no database.

Link validation, YAML parsing, HTML sanity, and diagram presence can be checked before any runtime test. These checks do not replace browser review.

Markdown link check
python - <<'PY'
import pathlib, re
root = pathlib.Path('.')
broken = []
for path in root.rglob('*.md'):
    if '.git' in path.parts:
        continue
    text = path.read_text(encoding='utf-8')
    for target in re.findall(r'\]\(([^)#]+)', text):
        if target.startswith(('http', 'mailto:', '#')):
            continue
        if not (path.parent / target).resolve().exists():
            broken.append(f'{path}: {target}')
print('\n'.join(broken) or 'No broken local links')
PY
Runtime verification

Only after configuration.

verify_project.py checks imports, connectivity, required tables, security managers, authentication, role-request support, and SQL assets.

terminal · after setup
python verify_project.py

Do not run it without a backend.A missing GUI or database dependency will fail for environmental reasons, not because the security code is wrong.

Negative testing

A happy path proves very little.

Every control class needs at least one refusal with a recorded reason. Use disposable demo data and keep evidence free of secrets.

Acceptance checklist

  • TA can record assigned attendance and cannot see grades.
  • Instructor can grade an assigned course and not an unassigned one.
  • Student sees own published records and no other student's data.
  • Small and MIN/MAX aggregates are rejected with a reason.
  • Secret export and print/copy/save follow policy.
  • Encrypted fields are ciphertext in a raw query.
  • Audit contains both success and denial events.
  • Five failures lock the account.

Known gaps

What is not automated yet.

No unit suite

RBAC, MLS, inference, flow, and encryption managers do not have automated unit tests.

No integration proof

No test proves every code path blocks an unassigned course write.

No UI automation

The Tkinter client is tested manually. Session expiry also lacks an automated test.

Limited injection review

Parameterised queries are used, but there is no broad SQL-injection test suite.

Incomplete grant coverage

Not every database grant and denial has a corresponding automated assertion.

No security scanning

Continuous dependency and secret scanning are roadmap items, not current practice.
